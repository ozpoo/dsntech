Course Modules: Design Technology II

MO 1: Interaction Foundations

Introduction

Welcome to Module 1. This module expands your foundational design literacy into interaction design and information architecture. Instead of focusing solely on how an interface looks, you will explore how it works and how people navigate information. You will learn to map out user journeys, conduct foundational research, and create structural wireframes for a complex digital task, culminating in an interactive information experience.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 1.1: Conduct foundational user research, task analysis, and journey mapping to understand user behavior. (Research)
  • MLO 1.2: Analyze user journeys, task flows, and the information architecture of complex systems to structure digital experiences. (Cognition)
  • MLO 1.3: Utilize industry-standard prototyping tools to design and wireframe screen-based experiences. (Tools)
  • MLO 1.4: Perform usability testing on prototypes and iterate based on actionable feedback. (Research)

Readings & Resources

  • Read: Atomic Design by Brad Frost – Chapter 1: Designing Systems
  • Read: Nielsen Norman Group: Introduction to Information Architecture and UX Heuristics Workbook
  • Watch: Figma Tutorials: Getting Started with Wireframing and Prototyping Basics

Weekly Lecture & Lab Breakdown

Week 1:

  • TUE Lecture: Interaction Logic — Task analysis, friction identification, and cognitive mapping.
  • THU Lab: Journey Mapping Workbench — Building user flows and task diagrams in FigJam.

Week 2:

  • TUE Lecture: Information Architecture — Tree testing, sitemaps, and mental models.
  • THU Lab: Wireframe Architecture — Setting up low-fidelity Figma canvases and frame grids.

Week 3:

  • TUE Lecture: Structural Hierarchy — Grayscale constraints, reading order, and affordances.
  • THU Lab: Grayscale Production — Building 5–7 core task wireframes without visual styling.

Week 4:

  • TUE Lecture: Usability & Feedback — Conducting usability tests and analyzing feedback loops.
  • THU Lab: Prototype Testing — Linking wireframes into clickable flows and running peer audits.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): Critique an existing application's user flow. Identify a point of friction and sketch an alternative solution.
  • Assignment (THU Lab Deliverable): Project 1 Process Book: Submit user journey maps, IA diagrams, and low-fidelity Figma wireframe links.
  • Quiz: UX Usability Heuristics and Task Analysis Basics.

MO 2: Components and Design Systems

Introduction

In Module 2, we shift our focus from creating individual design assets to building reusable, scalable rules and components. You will master the technical logic of modern UI design by building a robust component library. This module introduces you to atomic design principles, auto-layout, global variables, and design tokens, challenging you to think like a system designer rather than a static visual artist.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 2.1: Distinguish between static design assets and reusable, scalable design components. (Cognition)
  • MLO 2.2: Construct and manage component libraries, global variables, and design tokens within Figma. (Tools)
  • MLO 2.3: Document design systems comprehensively for developer and cross-functional handoff, maintaining clear governance. (Future-Focused Professional)
  • MLO 2.4: Implement advanced web accessibility standards (WCAG guidelines) into design tokens and components. (Advocacy)

Readings & Resources

  • Read: Atomic Design by Brad Frost – Chapters 2 & 3: The Atomic Design Methodology and The Design System Life Cycle
  • Read: Material Design Guidelines: Understanding Design Tokens
  • Watch: Figma Community: Deep Dive into Advanced Components, Auto-Layout, and Variables

Weekly Lecture & Lab Breakdown

Week 5:

  • TUE Lecture: Atomic Systems — Atoms, molecules, organisms, and component breakdown theory.
  • THU Lab: Auto-Layout Workshop — Mastering padding, gap constraints, and responsive resizing.

Week 6:

  • TUE Lecture: Tokenization — Global vs. alias tokens, naming conventions, and dark mode mechanics.

  • THU Lab: Variable Programming — Setting up color, typography, and spacing variables in Figma.

Week 7:

  • TUE Lecture: Component States — Variant properties, component sets, and Boolean toggles.
  • THU Lab: Interactive UI Kit Build — Constructing nested buttons, inputs, and card components.

Week 8:

  • TUE Lecture: System Governance — Library updates, cross-functional communication, and Dev Mode logic.
  • THU Lab: Handoff Documentation — Building component specification sheets and developer guidelines.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): Tokenization Exercise. Share your strategy for naming global color and typography variables for light and dark modes.
  • Assignment (THU Lab Deliverable): Project 2 Deliverables: Submit your organized Figma library featuring nested components, variants, design tokens, and a handoff sheet.

MO 3: Motion and Behavior

Introduction

Design doesn't sit still. Module 3 introduces time, transitions, and state changes as core communicative tools. You will explore motion principles to discover how subtle interface reactions act as "affordances" and feedback loops that guide human behavior. By animating micro-interactions and transitions, you will learn to manage user expectations across states and time.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 3.1: Execute temporal and state-based animations using timeline or interaction tools. (Tools)
  • MLO 3.2: Understand the programmatic logic of nested components and interactive state changes. (Cognition)
  • MLO 3.3: Experiment with motion, feedback loops, and temporal transitions as core communication tools. (Creative Confidence)
  • MLO 3.4: Evaluate the effectiveness of motion and affordances in guiding user behavior clearly and professionally. (Research / Professional)

Readings & Resources

  • Read: Nielsen Norman Group: The Role of Animation in UX Design
  • Read: Material Design Guidelines: Motion Principles and Choreography
  • Watch: Figma / Principle Video Guide: Mastering Smart Animate, Micro-interactions, and Component States

Weekly Lecture & Lab Breakdown

Week 9:

  • TUE Lecture: Motion Theory — Easing functions, duration standards, and functional vs. decorative motion.
  • THU Lab: Smart Animate Setup — Building basic hover states, toggles, and modal transitions.

Week 10:

  • TUE Lecture: Micro-Interactions — Trigger-rule-feedback loops and managing user expectations.
  • THU Lab: Interactive State Lab — Animating form validations, loading states, and inline feedback.

Week 11:

  • TUE Lecture: System Choreography — Multi-screen transitions, shared element transitions, and spatial continuity.
  • THU Lab: Prototype Construction — Connecting component states across multi-screen application flows.

Week 12:

  • TUE Lecture: Motion Evaluation — Auditing motion accessibility (reduced motion settings) and usability.
  • THU Lab: Recording & Export — Recording high-resolution prototype walkthroughs and exporting motion specs.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): Upload a screen recording of an effective micro-interaction from an app you use daily and write a brief analysis of its feedback mechanics.
  • Assignment (THU Lab Deliverable): Project 3 Prototype: Submit an interactive prototype showcasing micro-interactions, complex state transitions, and a video walkthrough demonstrating system choreography.

MO 4: Responsive and Generative Systems

Introduction

The final module addresses the beautiful unpredictability of modern digital environments. Devices change, screen sizes shift, data is dynamic, and artificial intelligence is reshaping how content is generated. In Module 4, you will design fluid, responsive ecosystems that gracefully handle varying data inputs, API integrations, and AI workflows while championing accessibility and ethical data patterns.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 4.1: Implement responsive layouts that adapt fluidly across multiple breakpoints. (Tools)
  • MLO 4.2: Integrate APIs, dynamic content, or generative AI workflows into design mockups and design systems. (Tools / Creative Confidence)
  • MLO 4.3: Design systems that degrade gracefully for users with low bandwidth or older devices. (Advocacy)
  • MLO 4.4: Evaluate generative systems and AI models for inherent biases or exclusionary defaults while advocating for ethical data patterns. (Advocacy)

Readings & Resources

  • Read: Ruined by Design by Mike Monteiro (Selected Chapters on design ethics, data privacy, and advocacy)
  • Read: W3C: Web Content Accessibility Guidelines (WCAG) Overview
  • Watch: Design Lecture Series: Designing with Dynamic Data, APIs, and Generative Artificial Intelligence

Weekly Lecture & Lab Breakdown

Week 13:

  • TUE Lecture: Fluid Screen Systems — Responsive layout rules, container constraints, and breakpoint architecture.
  • THU Lab: Multi-Breakpoint Workbench — Building adaptive frames using auto-layout wrap and fill rules.

Week 14:

  • TUE Lecture: Dynamic Content & AI — Designing for dynamic inputs, API data streams, and generative interface states.
  • THU Lab: Dynamic Data Integration — Populating Figma components with live JSON/API data plugins.

Week 15:

  • TUE Lecture: Ethical System Advocacy — Dark patterns, privacy considerations, and designing for low bandwidth.
  • THU Lab: Accessibility Audit & Final Handoff — Running WCAG color contrast checkers and finalizing documentation.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): Ethical Tech Case Study. Analyze a modern AI platform or dynamic application regarding privacy and bias using Monteiro's text.
  • Assignment (THU Lab Deliverable): Project 4 Presentation: Submit a multi-breakpoint responsive prototype powered by dynamic content/mock APIs, alongside a 2-page design essay auditing accessibility and ethical patterns.
  • Quiz: Comprehensive Exam (WCAG guidelines, design system governance, and responsive principles).
