Course Units: Design Technology II

Unit 1 — Interaction Foundations

Focus: Designing information for use and navigation.

Project Direction: Design an interactive information experience.

Topics

  • information architecture
  • user journeys
  • user research
  • task analysis
  • wireframes
  • prototyping
  • usability evaluation

Unit 2 — Components and Design Systems

Focus: Moving from assets toward reusable systems.

Project Direction: Build a component-based design system.

Topics

  • assets versus components
  • reusable patterns
  • components
  • variables
  • design tokens
  • documentation
  • governance
  • scalable systems

Unit 3 — Motion and Behavior

Focus: Communication through time, feedback, and interaction.

Project Direction: Design a motion-enhanced interactive experience.

Topics

  • motion principles
  • transitions
  • animation
  • state changes
  • affordances
  • feedback systems
  • time-based communication

Unit 4 — Responsive and Generative Systems

Focus: Design systems that adapt to context, content, and emerging technologies.

Project Direction: Develop a responsive, generative, or adaptive design system.

Topics

  • responsive systems
  • dynamic content
  • APIs
  • computational design
  • AI-assisted workflows
  • generative processes
  • adaptive experiences
