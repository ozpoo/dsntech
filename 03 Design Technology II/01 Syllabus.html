Course Syllabus: Design Technology II

Systems + Interaction + Behavior

Credits: 3

Format: Lecture + Lab

Meeting Schedule:

  • TUE: Lecture / Orchestrator (1 hr 10 min) — Cohort-wide instructional session focused on interaction logic, systemic frameworks, design ethics, behavior theory, and live technology demonstrations.
  • THU: Lab / Breakout Orientator (50 min) — Immediate hands-on breakout lab focused on component construction, prototyping, Figma variable workflows, micro-interaction tuning, and guided project execution.

Course Description

Design Technology II expands foundational technological literacy into systems thinking, interaction design, responsiveness, and behavior through an integrated Lecture + Lab model.

Tuesday lectures establish the theoretical, cognitive, and ethical foundations of interaction—examining atomic design methodologies, usability heuristics, dynamic data logic, and generative AI implications.

Thursday labs provide an intensive, guided environment where students build reusable design systems, program interactive variables, prototype motion behaviors, and construct responsive interfaces across modern software environments.

Core Questions

  • How do people interact with information?
  • How do systems create consistency and adaptability?
  • How does design behave over time?
  • How do technologies shape user experience?
  • How can systems evolve across contexts?
  • How do emerging technologies influence design practice?

Student Outcome

Students become capable of designing interactive, responsive, and scalable systems that support contemporary communication across media while mastering component-driven tools in lab and systemic thinking in lecture.

Course Structure: Lecture vs. Lab Cadence

  • TUE Lecture (Systems & Behavior): Focuses on interaction paradigms, information architecture theory, design tokens, component architecture logic, motion choreography, and critical assessments of AI bias and WCAG web accessibility.
  • THU Lab (Execution & Prototyping): Focuses on technical execution in Figma and prototyping environments—constructing component libraries, mapping variables, setting up Smart Animate transitions, building responsive auto-layouts, and conducting usability tests.

Course Outcomes and Learning Objectives

Students who successfully complete this course will have demonstrated competency across the following areas, grounded in the framework for future-ready practice:

TOOLS

Course Outcome: Develop fluency in interaction design software, prototyping environments, and component-based workflows to build responsive systems.

  • Lecture Focus: Analyze the architecture of component-based design systems, variable scoping logic, timeline motion mechanics, and dynamic API integrations.
  • Lab Focus: Build Figma component libraries, program global variables/tokens, execute state-based animations, and construct auto-layouts with multi-breakpoint responsiveness.

Objectives:

  • Utilize industry-standard prototyping tools (e.g., Figma) to design screen-based experiences.
  • Construct and manage component libraries, global variables, and design tokens.
  • Execute temporal and state-based animations using timeline or interaction tools.
  • Integrate APIs, dynamic content, or generative AI workflows into design mockups.
  • Implement responsive layouts that adapt fluidly across multiple breakpoints.

COGNITION

Course Outcome: Expand structural thinking into systemic and behavioral thinking, designing rules rather than singular artifacts.

  • Lecture Focus: Study user journey mapping, task analysis frameworks, information architecture, and the logic of state changes over time.
  • Lab Focus: Translate user flows into low-fidelity structural wireframes, configure nested component variants, and map dynamic state interactions.

Objectives:

  • Distinguish between static design assets and reusable, scalable design components.
  • Analyze user journeys, task flows, and the information architecture of complex systems.
  • Understand the programmatic logic of variables, nested components, and state changes.
  • Anticipate how information behaves over time and responds to context or device changes.

CREATIVE CONFIDENCE

Course Outcome: Embrace the unpredictability of interactive and generative media through rapid prototyping and user testing.

  • Lecture Focus: Evaluate feedback loops, affordances, motion mechanics, and human-AI collaborative workflows.
  • Lab Focus: Prototype interactive state transitions, conduct rapid usability tests, iterate based on user feedback, and test generative prompt integrations.

Objectives:

  • Prototype interactive experiences quickly to test functional hypotheses.
  • Adapt design systems gracefully when introduced to unexpected user behavior or dynamic content.
  • Experiment with motion, feedback loops, and temporal transitions as core communication tools.
  • Navigate emerging technologies and AI generation as collaborative, rather than prescriptive, design tools.

RESEARCH

Course Outcome: Base interaction and system decisions on user observation, usability heuristics, and testing data.

  • Lecture Focus: Analyze usability heuristics (Nielsen Norman Group), task analysis methodologies, and motion affordance principles.
  • Lab Focus: Conduct user testing on interactive prototypes, track task success metrics, and audit motion effectiveness.

Objectives:

  • Conduct foundational user research, task analysis, and journey mapping.
  • Perform usability testing on prototypes and iterate based on actionable feedback.
  • Evaluate the effectiveness of motion and affordances in guiding user behavior.

FUTURE FOCUSED PROFESSIONAL

Course Outcome: Master the documentation, governance, and collaborative handoff processes required for modern digital product teams.

  • Lecture Focus: Study design system governance models, tokenization naming conventions, developer handoff standards, and version control.
  • Lab Focus: Author Figma Dev Mode specifications, create token handoff sheets, and manage shared component library updates.

Objectives:

  • Document design systems comprehensively for developer and cross-functional handoff.
  • Manage component versioning and library updates within a collaborative team environment.
  • Articulate interactive behaviors and logic clearly using professional terminology.

ADVOCACY

Course Outcome: Champion inclusive design, prioritize digital accessibility, and critically assess the societal impact of systemic technology choices.

  • Lecture Focus: Critique algorithmic bias in generative models, discuss user privacy ethics (Ruined by Design), and evaluate WCAG accessibility standards.
  • Lab Focus: Perform contrast calculations on design tokens, build screen-reader accessible wireframe structures, and test graceful degradation patterns.

Objectives:

  • Implement advanced web accessibility standards (WCAG guidelines, screen reader compatibility).
  • Evaluate generative systems and AI models for inherent biases or exclusionary defaults.
  • Design systems that degrade gracefully for users with low bandwidth or older devices.
  • Advocate for user privacy, ethical data patterns, and transparent systemic behavior.

Course Materials & Technologies

  • Textbook: Ruined by Design by Mike Monteiro (for ethical/advocacy context) or Atomic Design by Brad Frost (for systems context)
  • OER Resources: WCAG Accessibility Guidelines, Nielsen Norman Group articles on UX heuristics
  • Core Software: Figma (including Dev Mode, Auto-Layout, Variables, and Prototyping)
  • Motion & Behavior Tools: Figma Smart Animate, Principle, or After Effects
  • Emerging Tech: Generative AI tools (e.g., Midjourney, ChatGPT) and mock API endpoints
  • Reference: Figma community documentation, material design guidelines

Learning Activities & Assessments

  • Information Architecture & Wireframing (Lab Benchmark): Map a user journey and create structural wireframes for a complex digital task. This assesses research, task analysis, and cognitive organization.
  • Component-Based Design System (Lecture + Lab): Build a scalable UI kit utilizing variables, auto-layout, and nested components. This evaluates technical mastery of tools and systemic thinking.
  • Motion & Micro-Interaction Prototype (Lecture + Lab): Design state changes, transitions, and feedback loops for an interface. This assesses the understanding of temporal communication and behavior.
  • Generative/Responsive Environment (Lab Focus): Design a system that adapts its content or layout based on varying data inputs, user contexts, or generative prompts. This evaluates adaptability and emerging technology literacy.
