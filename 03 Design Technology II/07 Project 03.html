Project 03: Designing Behavior

Motion, Interaction & Prototype Choreography

Canvas Assignment Settings:

  • Points: 200
  • Submission Type: Online
    Website URL / Figma Link + File Upload
  • Allowed File Types: .mp4 (Prototype Walkthrough), .pdf (Motion Documentation)

Project Overview

Static interfaces communicate structure—but interactive interfaces communicate behavior. Every button press, transition, loading indicator, and animation teaches users how a system responds. Well-designed motion reduces cognitive load, reinforces hierarchy, and provides meaningful feedback, helping users understand both where they are and what happens next.

For this project, introduced during Tuesday Lecture and refined throughout Thursday Labs, you will transform the design system created in Project 2 into a fully interactive prototype. Rather than focusing on visual aesthetics alone, you will choreograph how your interface behaves across time through micro-interactions, transitions, and state changes.

Using Figma’s prototyping tools, Smart Animate, interactive components, and motion principles, you will design an experience that feels responsive, intuitive, and intentional. Every animation should serve a purpose—guiding attention, communicating system status, or reinforcing user actions.

Pillars Addressed: Systems, Cognition, Research, Creative Confidence

Course Outcomes: Create interactive prototypes, implement motion as a communication tool, and evaluate interface behavior through usability testing and iterative refinement.

Learning Objectives

By the end of this project, you will be able to:

  1. Apply motion principles to communicate feedback, hierarchy, and state changes.
  2. Build interactive component behaviors using variants and prototype connections.
  3. Design multi-screen transitions that reinforce user understanding and navigation.
  4. Evaluate and refine interface behavior through usability testing and accessibility considerations.

Lecture vs. Lab Execution Schedule

  • TUE Lecture Briefing: Motion theory, temporal design, easing, interaction feedback, accessibility considerations, and cognitive load.
  • THU Lab Execution: Smart Animate implementation, interactive component states, prototype construction, usability testing, motion refinement, and video documentation.

Step-by-Step Instructions

The Scenario

Continue developing the application you designed in Projects 1 and 2.

Your design system now contains reusable components, but it still behaves like a collection of static screens. Your task is to bring the interface to life by designing meaningful interactions that communicate with the user through motion and feedback.

Imagine your prototype will be demonstrated to stakeholders who need to understand not only what the interface looks like, but how it behaves during real-world use.

Part 1: Interactive Component Behaviors

(Lecture Theory / Lab Construction)

Transform your static components into interactive elements by creating meaningful behavioral states.

At minimum, demonstrate interactions for:

  • Buttons
  • Form fields
  • Navigation elements
  • Menus or overlays
  • Toggles, switches, or selection controls

Each interaction should clearly communicate user input and system response.

Part 2: Micro-Interactions & Feedback

(Lab Execution)

Design subtle interface behaviors that improve communication between the user and the system.

Include examples such as:

  • Hover feedback
  • Loading indicators
  • Success and error states
  • Form validation
  • Progress indicators
  • Confirmation messages

Every motion decision should improve usability rather than simply decorate the interface.

Part 3: Screen Transitions & User Flow

(Lab Execution)

Connect your screens into a complete interactive experience.

Design smooth transitions that reinforce spatial relationships and guide users through the task established in Project 1.

Consider:

  • Navigation between screens
  • Modal presentations
  • Shared element transitions
  • Overlay behaviors
  • Back navigation
  • Progressive disclosure of information

Your prototype should demonstrate a complete user journey from beginning to end.

Part 4: Motion Evaluation & Accessibility

(Lecture Review / Lab Testing)

Evaluate your prototype through peer usability testing.

Refine your prototype based on observed user behavior and document your revisions.

Consider:

  • Motion timing
  • Ease of navigation
  • Clarity of interaction feedback
  • Reduced-motion accessibility
  • Cognitive load
  • Overall usability

Document the major improvements made after testing.

Submission Requirements

Please submit the following:

  1. Prototype Walkthrough (.mp4): A 2–4 minute screen recording demonstrating your interactive prototype, highlighting key transitions, micro-interactions, and system behaviors while briefly explaining your design decisions.
  2. Motion Documentation (PDF): A concise document illustrating your interaction states, transition logic, usability findings, and revisions made following peer feedback.
  3. Figma Link (URL): A link to your completed interactive prototype containing connected screens, interactive components, and motion behaviors. (Crucial: Ensure link sharing is set to “Anyone with the link can view.”)
