Course Modules: Design Technology I

MO 1: Digital Foundations**

Introduction

Welcome to Module 1. Before launching into complex visual design, you must master the environment in which you work. This module establishes your personal digital infrastructure. You will learn to treat file paths, cloud syncing, metadata, and folder structures not as administrative chores, but as intentional design decisions. This module culminates in the Asset System Project, where you will build and test a professional, scalable storage and backup framework that will support your entire design career.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 1.1: Navigate local, networked, and cloud OS environments to establish resilient file management and version control structures. (Future Focused Professional)
  • MLO 1.2: Install fonts, manage font licenses, and differentiate between application-specific and universal file formats. (Tools / Advocacy)
  • MLO 1.3: Articulate how data storage structures, metadata, and file naming conventions impact collaborative studio workflows. (Cognition)

Readings & Resources

  • Read: Graphic Design Rules, Section: "File Management and Organization Basics" (or equivalent chapter on workflow).
  • Read: "Understanding File Formats: Native vs. Exchange Files" (Adobe Workflow Documentation).
  • Watch: Mastering the OS: Local Storage vs. Cloud Syncing Mechanics (Instructor Video Tutorial).

Weekly Lecture & Lab Breakdown

Week 1:

  • TUE Lecture: System Architecture — OS logic, directory paths, file-naming protocols, and cloud vs. local storage models.
  • THU Lab: Local Infrastructure Setup — Building folder trees, establishing naming conventions, and configuring backup syncing.

Week 2:

  • TUE Lecture: Asset Integrity — Font licensing, copyright, metadata preservation, and catastrophe-proofing your workflow.
  • THU Lab: System Audit & Testing — Font installer navigation, SSD drive partition setup, and live peer directory reviews.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): "The Ethics of Typography: Font Licensing and Piracy in Modern Studio Practice."
  • Assignment (THU Lab Deliverable): Asset System Setup: Submit a PDF manual and a live shared cloud directory link demonstrating your standardized folder structure and backup protocol.
  • Quiz: Digital Environment & File Format Literacy Quiz.

MO 2: Media, Materials, and Translation

Introduction

A design is never independent of its medium. In Module 2, you will discover how a single visual idea morphs when it moves between a glowing screen and a physical sheet of paper. Through the Cross-Media Translation Project, you will author a single visual concept and translate it into two distinct outputs: an optimized print poster and a screen-ready graphic. Along the way, you will wrestle directly with the math of resolution, the mechanics of color spaces, and the constraints of physical substrates.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 2.1: Execute fundamental raster operations in Photoshop and vector construction in Illustrator. (Tools)
  • MLO 2.2: Translate a single visual system across print and digital media, successfully calculating resolution differences (300dpi vs. 72dpi) and shifting between CMYK/Pantone and RGB/Hexadecimal color spaces. (Creative Confidence / Research)
  • MLO 2.3: Analyze the production implications of color space conversion, ink limits, and paper substrate selection on visual fidelity. (Research)

Readings & Resources

  • Read: Graphic Design Rules, Rules: "Color Spaces (RGB vs. CMYK)" and "Resolution Realities."
  • Read: The Designer's Guide to Print Production & Substrates (Manufacturer Documentation).
  • Watch: How to Preflight, Package, and Export Clean Files for Commercial Print Vendors (Screencast).

Weekly Lecture & Lab Breakdown

Week 3:

  • TUE Lecture: Vector vs. Raster Logic — Geometry vs. pixel arrays, software domain boundaries, and color space theory.
  • THU Lab: Vector Construction & Image Editing — Pen tool efficiency, raster manipulation, and color mode configuration in Illustrator/Photoshop.

Week 4:

  • TUE Lecture: The Math of Output — DPI/PPI formulas, effective resolution, screen refresh considerations, and file compression.
  • THU Lab: Media Translation Workbench — Resampling images, converting color profiles, and setting up bleed/crop boundaries.

Week 5:

  • TUE Lecture: Substrates & Sustainability — Paper weight, ink limits, digital weight optimization, and environmental impacts of production.
  • THU Lab: Preflight Lab & Vendor Handoff — Running preflight profiles, packaging files with linked assets, and generating production PDFs.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): "The Ecological Footprint of Media: Comparing the Environmental Impact of Print vs. High-Weight Digital Assets."
  • Assignment (THU Lab Deliverable): Cross-Media Translation Deliverables: Submit an interactive PDF package containing a print-ready vector/raster poster file (packaged with links/fonts) alongside a web-optimized screen graphic asset.
  • Quiz: Vector vs. Raster Logic and Color Space Mechanics.

MO 3: Publication and Information Systems

Introduction

How do you guide a reader through thousands of words of text across dozens of pages? Module 3 introduces systems thinking through typography and layout architecture. You will shift your focus from single-page layouts to complex, multi-page documents. In the Publication System Design Project, you will use InDesign to tame complex text copy, establishing visual hierarchy using modular typographic scales, baseline grids, master pages, and automated text styles.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 3.1: Apply advanced layout software tools in InDesign, including master pages, paragraph styles, character styles, and automated text threading. (Tools)
  • MLO 3.2: Understand and implement the mathematical logic of typographic grids and modular scales alongside their aesthetic application. (Cognition)
  • MLO 3.3: Organize complex text copy into a highly scannable, logical information hierarchy across a multi-page publication layout. (Cognition / Creative Confidence)

Readings & Resources

  • Read: Graphic Design Rules, Section: "The Grid: Breaking it, Making it" and "Typographic Hierarchy Dos and Don'ts."
  • Read: Adobe InDesign Documentation: "Working with Paragraph and Character Styles."
  • Watch: The Power of the Baseline: Aligning Multi-Column Typographic Layouts (Video Walkthrough).

Weekly Lecture & Lab Breakdown

Week 6:

  • TUE Lecture: Typographic Systems & Grids — Baseline grid math, column structures, modular proportions, and typographic hierarchy.
  • THU Lab: Grid Construction — Document setup in InDesign, baseline grid mapping, and margins/column configuration.

Week 7:

  • TUE Lecture: Automation Mechanics — Style sheets, parent page inheritance, running headers, and multi-page layout logic.
  • THU Lab: Stylesheet Workshop — Creating nested paragraph/character styles, object styles, and master page templates.

Week 8:

  • TUE Lecture: Information Flow & Copyfitting — Managing complex long-form copy, widows/orphans, text threading, and prepress checks.
  • THU Lab: Multi-Page Production & Preflight — Threading long text, fine-tuning rag/hyphenation, and exporting print-ready publication packages.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): "Copyright, Creative Commons, and Intellectual Property Rights for Layout Designers."
  • Assignment (THU Lab Deliverable): Multi-Page Publication System: Submit a multi-page, packaged InDesign layout demonstrating grid enforcement, parent page mapping, and clean paragraph/character style sheets.
  • Quiz: Typographic Math, Grids, and Software Hierarchy.

MO 4: Structured Screen Media

Introduction

In this final module, you will learn to view web design not as drawing pictures of web pages, but as building responsive, flexible information systems. In the Responsive Screen Build Project, you will translate the multi-page print publication system you designed in Module 3 into a functioning, responsive website. Using VS Code, you will write semantic HTML and CSS Grid layouts to ensure your text fluidly adapts to any screen size while remaining completely accessible to users with disabilities.

Module Learning Objectives (MLOs)

Upon completion of this module, you should be able to:

  • MLO 4.1: Build semantic HTML structures and style them using CSS Grid and flexbox frameworks. (Tools)
  • MLO 4.2: Translate a static print typographic layout system into a dynamic, content-first, fluid screen environment. (Creative Confidence)
  • MLO 4.3: Integrate foundational web accessibility requirements (WCAG color contrast minimums, descriptive alt tags, and semantic structure) into custom web layouts. (Advocacy)

Readings & Resources

  • Read: Mozilla Developer Network (MDN) Web Docs: "Getting Started with HTML" and "CSS Grid Layout."
  • Read: Introduction to Web Accessibility (W3C): "Understanding Semantic Markup and Contrast."
  • Watch: Responsive Typography: Building Fluid Text with CSS Viewport Units (Coding Tutorial).

Weekly Lecture & Lab Breakdown

Week 9:

  • TUE Lecture: Print to Screen System Translation — Comparing static page bounds to fluid DOM trees, viewport mechanics, and text hierarchy.
  • THU Lab: VS Code & File Structure Setup — Setting up local web directories, root folders, relative file paths, and live-server environments.

Week 10:

  • TUE Lecture: Semantic Markup & Architecture — HTML structure, document object models (DOM), head/body relationships, and semantic tags.
  • THU Lab: Writing Semantic HTML — Translating publication text into <header>, <nav>, <main>, <article>, and <footer> elements.

Week 11:

  • TUE Lecture: CSS Foundations & The Box Model — Selectors, specificity, margins, padding, borders, and typography styling rules.
  • THU Lab: Styling Workshop — Linking external CSS files, defining typography properties, and managing box-model spacing.

Week 12:

  • TUE Lecture: Fluid Layouts & Grid Mechanics — CSS Grid, Flexbox, fractional units (fr), and media query logic.
  • THU Lab: Building CSS Grids — Writing fluid grid structures, flex containers, and mobile/desktop breakpoint shifts.

Week 13:

  • TUE Lecture: Inclusive Design & WCAG Standards — Accessibility principles, color contrast calculations, screen readers, and alt-text strategy.
  • THU Lab: Accessibility Auditing — Running accessibility checkers, resolving contrast errors, adding ARIA labels, and testing keyboard navigation.

Week 14:

  • TUE Lecture: AI in Code & Optimization — Front-end automation tools, asset weight optimization, clean code practices, and deployment pipelines.
  • THU Lab: Final Build Packaging — Optimizing web image assets, validating code syntax, and bundling the final deployment directory.

Activities & Assessments

  • Discussion (TUE Lecture Reflection): "The Ethics of AI in Code and Design: Automation, Attribution, and the Future of the Front-End Environment."
  • Assignment (THU Lab Deliverable): Responsive Web Build: Submit a working, multi-page front-end web directory (HTML, CSS, and optimized image assets) compressed into a clean deployment package.
  • Quiz: Semantic HTML, Basic CSS Syntax, and Accessibility Compliance.
