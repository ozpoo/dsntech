Project 02: Cross-Media Translation

Media, Materials, & Translation

Canvas Assignment Settings:

  • Points: 200
  • Submission Type: Online
    File Upload
  • Allowed File Types: .pdf, .zip

Project Overview

Design does not exist independently of its medium. A visual system that succeeds on a glowing phone screen may completely fail when printed on paper, and a poster designed for a press may become illegible when compressed into a social media graphic. Professional designers must understand not only how to create visuals, but how those visuals change as they move between different methods of production.

In this project, you will develop a single visual concept and intentionally translate it across two distinct media: a professionally prepared print poster and a screen-optimized digital graphic. Rather than creating two unrelated designs, you will build one cohesive visual system that adapts to the unique technical, physical, and perceptual requirements of each environment.

Throughout the project you will make informed decisions about raster versus vector graphics, color spaces, image resolution, typography, file optimization, and production workflows. By the end, you will understand that successful design is not simply about aesthetics—it is about choosing the right technical solution for a given medium.

Pillars Addressed: Creative Confidence, Research, Tools

Course Outcomes: Execute raster and vector workflows, translate visual systems across print and digital environments, and prepare production-ready files for professional output.

Learning Objectives

By the end of this project, you will be able to:

  1. Develop a unified visual concept that functions across multiple media.
  2. Apply vector and raster workflows appropriately for different production needs.
  3. Prepare files using correct color spaces, image resolutions, and export settings.
  4. Produce professional-quality print-ready and screen-ready deliverables using industry-standard workflows.

Lecture vs. Lab Execution Schedule

  • TUE Lecture Briefing: Principles of media translation, raster versus vector graphics, RGB versus CMYK color spaces, image resolution, substrates, and production workflows.
  • THU Lab Execution: Illustrator and Photoshop workflow demonstrations, image editing, vector construction, color profile conversion, preflight checks, packaging assets, and export optimization.

Step-by-Step Instructions

Part 1: Develop a Visual System

(Lecture Logic / Lab Planning)

Begin by creating a single visual concept centered around a topic of your choice (or one provided by the instructor). Your concept should include:

  • A clear visual hierarchy
  • Consistent typography
  • A defined color palette
  • Supporting imagery or illustration
  • A unified visual style

This concept will serve as the foundation for every deliverable in the project.

Part 2: Print Translation

(Lab Execution)

Translate your concept into a print-ready poster suitable for commercial production.

Your poster should include:

  • Appropriate page dimensions
  • Bleed and safety margins
  • CMYK color mode
  • High-resolution imagery (300 ppi minimum)
  • Properly prepared vector graphics
  • Organized layers and linked assets

Before exporting, perform a complete preflight review to identify missing fonts, broken links, or production errors.

Part 3: Screen Translation

(Lab Execution)

Adapt the same visual system into a digital graphic optimized for screen viewing.

Your digital version should demonstrate:

  • RGB color space
  • Appropriate pixel dimensions
  • Optimized file size
  • Legible typography on screen
  • Appropriate image compression
  • Export settings suited for digital distribution

Rather than simply resizing the poster, thoughtfully redesign the composition to accommodate the constraints and opportunities of digital media.

Part 4: Production Package

(Lab Deliverable)

Prepare a professional production package containing all project assets.

Your package should include:

  • Packaged Illustrator and/or Photoshop working files
  • Linked images
  • Required fonts (where licensing permits)
  • Print-ready PDF
  • Screen-ready PNG or JPG
  • A short production summary describing the technical decisions you made during translation

Submission Requirements

Please submit the following:

  1. Compressed Project Folder (.zip) containing:
    • Native Illustrator and/or Photoshop files
    • Packaged assets
    • Print-ready PDF
    • Screen-ready image
  2. Production Summary (PDF):
    A one-page document explaining:
    • Why different color spaces were used
    • How image resolution changed between outputs
    • Any design modifications required during translation
    • Challenges encountered and how they were resolved
