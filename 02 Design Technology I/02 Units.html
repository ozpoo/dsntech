Course Units: Design Technology I

Unit 1 — Digital Foundations

Focus: Understanding the digital environment as a design environment.

Project Direction: Create and manage a personal design asset system.

Topics

  • operating systems
  • file organization
  • metadata
  • cloud and local storage
  • asset management
  • fonts and licensing
  • file formats
  • raster and vector media
  • workflow fundamentals
  • information organization
  • naming and versioning systems

Unit 2 — Media, Materials, and Translation

Focus: Understanding how visual information changes across media.

Project Direction: Translate a visual concept across multiple media outputs while evaluating how material and technological constraints affect communication.

Topics

  • image editing
  • vector construction
  • asset preparation
  • format conversion
  • color systems
  • color spaces
  • reproduction technologies
  • paper systems
  • substrates
  • ink and print technologies
  • fidelity and reproduction
  • media constraints
  • adaptation across formats

Unit 3 — Publication and Information Systems

Focus: Structure, hierarchy, and communication through layout systems.

Project Direction: Design a publication system that organizes complex information across multiple pages and formats.

Topics

  • typographic systems
  • hierarchy systems
  • modular scales
  • grids
  • information architecture
  • content organization
  • content hierarchy
  • publication workflows
  • print production

Unit 4 — Structured Screen Media

Focus: Design as structure rather than appearance.

Project Direction: Translate a publication system into a responsive screen-based experience.

Topics

  • HTML
  • CSS
  • semantic structure
  • accessibility
  • responsive layouts
  • content-first design
  • web standards
  • screen-based production
  • responsive typography
