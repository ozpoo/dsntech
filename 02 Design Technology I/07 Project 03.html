Project 03: Publication Systems

Publication & Information Systems

Canvas Assignment Settings:

  • Points: 250
  • Submission Type: Online
    File Upload
  • Allowed File Types: .pdf, .zip

Project Overview

Designing a single page is one challenge. Designing dozens of pages that remain clear, consistent, and easy to navigate is another entirely. Professional publications rely on systems—not individual decisions—to organize information. Grids, typographic scales, paragraph styles, parent pages, and document architecture allow designers to maintain consistency while managing large amounts of content efficiently.

In this project, you will transform an existing body of text into a professionally designed multi-page publication using Adobe InDesign. Rather than focusing on illustration or expressive composition, your primary objective is to create a structured information system that guides readers through complex content with clarity and consistency.

Throughout the project, you will develop a modular layout using baseline grids, columns, reusable styles, and automated document features. You will discover that thoughtful systems reduce repetitive work, improve readability, and allow large publications to evolve without sacrificing visual cohesion.

By the end of this project, you will understand that publication design is less about decorating pages and more about building repeatable frameworks that organize information at scale.

Pillars Addressed: Cognition, Creative Confidence, Tools

Course Outcomes: Apply advanced InDesign workflows, organize complex information through typographic systems, and produce professionally packaged multi-page publications.

Learning Objectives

By the end of this project, you will be able to:

  1. Design a modular publication system using grids and typographic hierarchy.
  2. Apply paragraph styles, character styles, object styles, and parent pages to automate document consistency.
  3. Organize long-form content into a clear, readable information hierarchy.
  4. Prepare a production-ready publication package suitable for professional printing or distribution.

Lecture vs. Lab Execution Schedule

  • TUE Lecture Briefing: Typographic hierarchy, modular grids, baseline grids, document architecture, parent pages, style automation, and long-form publication workflows.
  • THU Lab Execution: InDesign document setup, grid construction, stylesheet creation, threaded text, copyfitting, preflight review, packaging, and PDF export.

Step-by-Step Instructions

Part 1: Build the Publication Framework

(Lecture Logic / Lab Planning)

Begin by establishing the structural foundation of your publication before placing any content.

Your publication framework should include:

  • Document size and margins
  • Multi-column grid system
  • Baseline grid
  • Master (Parent) pages
  • Running headers and/or page numbering
  • Preliminary typographic scale

Think of this framework as the blueprint that every page will follow.

Part 2: Construct the Typographic System

(Lab Execution)

Develop a complete typographic hierarchy that will organize every level of information throughout the publication.

Create styles for:

  • Primary headings
  • Secondary headings
  • Body copy
  • Captions
  • Pull quotes or callouts
  • Lists and supporting text

Use Paragraph Styles, Character Styles, and Object Styles wherever appropriate instead of manually formatting text.

Part 3: Build the Publication

(Lab Execution)

Import the provided text (or instructor-approved content) into your document and organize it into a polished multi-page publication.

Your publication should demonstrate:

  • Threaded text across multiple pages
  • Consistent spacing and alignment
  • Effective hierarchy
  • Balanced typography
  • Proper handling of widows, orphans, and overset text
  • Consistent visual rhythm throughout the document

Images, graphics, and supporting elements should reinforce—not compete with—the information hierarchy.

Part 4: Production Package

(Lab Deliverable)

Prepare your publication for professional production.

Your submission package should include:

  • Native InDesign (.indd) file
  • Packaged document with linked assets
  • Fonts (when licensing permits)
  • Print-ready PDF
  • A one-page design rationale describing your layout system and workflow decisions

Before submitting, perform a complete preflight review to ensure there are no missing links, missing fonts, overset text, or export errors.

Submission Requirements

Please submit the following:

  1. Compressed Project Folder (.zip) containing:
    • Native InDesign document
    • Packaged project folder
    • Linked assets
    • Print-ready PDF
  2. Publication Design Summary (PDF):
    A one-page document explaining:
    • Your grid structure and layout decisions
    • How paragraph and character styles improved workflow
    • Challenges encountered while organizing large amounts of information
    • How your publication system could scale to additional pages

  • Project 01: Build a system for managing assets.
  • Project 02: Translate a system across media.
  • Project 03: Build a system for organizing information.
  • Project 04: Build a system that responds to users.

That progression makes the semester tell a coherent story: students aren’t just learning software—they’re learning to think like designers who create and manage systems.
