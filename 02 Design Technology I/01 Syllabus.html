Course Syllabus: Design Technology I

Media + Translation + Output

Credits: 3

Format: Lecture + Lab

Meeting Schedule:

  • TUE: Lecture / Orchestrator (1 hr 10 min) — Cohort-wide instructional session focused on core concepts, systems thinking, design history/ethics, technical logic, and live methodology demonstrations.
  • THU: Lab / Breakout Orientator (50 min) — Immediate hands-on breakout lab focused on tactical application, software execution, live troubleshooting, peer critique, and guided project development.

Course Description

Design Technology I introduces students to the technological foundations of contemporary design practice through an integrated Lecture + Lab structure.

Tuesday lectures establish essential systems thinking, digital media theory, technical logic, and production workflows.

Thursday labs provide an intensive, guided studio environment where students directly apply lecture concepts through hands-on software execution, file preflighting, live troubleshooting, and iterative project development across print, screen, and web environments.

Core Questions

  • How does design change across media?
  • How do production constraints influence design decisions?
  • How is information structured and organized?
  • How do workflows support effective design practice?
  • How do technologies shape communication?
  • What assumptions are built into the tools and systems we use?

Student Outcome

Students become capable of creating, organizing, translating, and producing design across multiple media while understanding the systems that support production.

Course Structure: Lecture vs. Lab Cadence

  • TUE Lecture (Systems & Logic): Focuses on technical theory, file environments, color/resolution science, grid mechanics, workflow architecture, and critical discussions around design ethics, web accessibility, and artificial intelligence.
  • THU Lab (Execution & Troubleshooting): Focuses on tactical tool application (Photoshop, Illustrator, InDesign, VS Code), file directory construction, font installation, code execution, live bug fixing, and peer feedback.

Course Outcomes and Learning Objectives

Students who successfully complete this course will have demonstrated competency across the following areas, grounded in the framework for future-ready practice:

TOOLS

Course Outcome: Develop foundational computer and file fluency as the prerequisite infrastructure for all design work across the program.

  • Lecture Focus: Analyze the mathematical logic of raster vs. vector environments, resolution standards (300 dpi vs. 72 dpi+), CSS grid frameworks, and color specification systems.
  • Lab Focus: Apply tools in Photoshop, Illustrator, InDesign, and VS Code; navigate OS environments; execute font installation; and preflight/export files for production.

Objectives:

  • Apply raster, vector, and layout tools (Photoshop, Illustrator, InDesign) at a foundational level.
  • Execute CSS grid implementation and fundamental HTML structuring.
  • Navigate the OS environment, establish file management structures, and execute font installation.
  • Distinguish between raster and vector environments and select the appropriate application for specific tasks.
  • Manage file formats effectively for applications, imagery, and typography.
  • Apply resolution standards appropriately for print (300 dpi) and digital output (72 dpi+).
  • Utilize correct color spaces (RGB, CMYK) and specification systems (Pantone, Hexadecimal).
  • Prepare, preflight, and export files for physical and digital production.

COGNITION

Course Outcome: Understand the digital environment as the conceptual foundation for all design work, treating files, formats, tools, and workflows as intentional design decisions.

  • Lecture Focus: Articulate the relationship between operating systems, storage environments, and the programmatic mechanics of typographic grids.
  • Lab Focus: Implement proper file format selection based on output media and build structured grid systems directly within software tools.

Objectives:

  • Articulate how operating systems, files, folders, applications, and storage environments relate.
  • Understand the conceptual and mathematical differences between raster and vector logic.
  • Select appropriate file formats based on media constraints and output contexts.
  • Recognize technology as an extension of visual design, not an isolated technical track.
  • Understand programmatic mechanics of typographic grids alongside their visual application.

CREATIVE CONFIDENCE

Course Outcome: Build comfort and technical fluency through design practice, cross-media translation, and active iteration.

  • Lecture Focus: Evaluate cross-media translation strategies, visual consistency across platforms, and workflow efficiency.
  • Lab Focus: Rapidly prototype visual concepts, experiment with toolsets during guided lab breakouts, and solve real-time software challenges.

Objectives:

  • Learn toolsets by solving applied design problems rather than isolated software tutorials.
  • Translate identical content systems across multiple media formats and technical environments.
  • Develop confidence in switching between distinct digital tools and production workflows.
  • Cultivate habits of rapid iteration and low-stakes experimentation in digital spaces.

RESEARCH

Course Outcome: Utilize technical knowledge and system constraints to make evidence-based production decisions.

  • Lecture Focus: Examine color space mechanics (RGB, CMYK, Pantone), substrate constraints, and sustainable digital asset optimization.
  • Lab Focus: Perform resolution testing, asset compression, color profile conversion checks, and substrate preparation in software.

Objectives:

  • Research and apply precise resolution, color, and format standards for specific output contexts.
  • Analyze the production implications of color space conversion and substrate selection.
  • Investigate sustainable digital production practices, including asset optimization and reducing digital weight.

FUTURE FOCUSED PROFESSIONAL

Course Outcome: Establish professional file management, organizational habits, and workflow conventions that scale into studio environments.

  • Lecture Focus: Study studio asset pipelines, version control logic, local vs. cloud storage architectures, and handoff protocols.
  • Lab Focus: Build uniform file naming conventions, construct local/cloud directory trees, and assemble handoff packages.

Objectives:

  • Implement consistent file naming, folder structuring, and version management systems.
  • Differentiate operational logic between local storage, networked environments, and cloud systems.
  • Develop organized handoff conventions for both print vendors and digital collaborators.

ADVOCACY

Course Outcome: Develop critical awareness of technology's embedded defaults, ethical implications, and accessibility requirements.

  • Lecture Focus: Discuss AI-assisted design ethics, copyright law, font licensing, and ecological impacts of digital media.
  • Lab Focus: Implement contrast accessibility checks, write WCAG-compliant semantic HTML, and verify font licensing in active project files.

Objectives:

  • Understand AI-assisted design capabilities, limitations, and current ethical considerations.
  • Navigate copyright, font licensing, and intellectual property within digital practice.
  • Apply foundational web accessibility standards, including semantic HTML and contrast requirements.
  • Recognize the ecological and material implications of both physical and digital production.

Course Materials & Technologies

  • Textbook: Graphic Design Rules: 365 Essential Design Dos and Don'ts (or equivalent foundational text)
  • OER Resources: Mozilla Developer Network (MDN) Web Docs for HTML/CSS standards
  • Reference: Manufacturer documentation for print standards and Adobe Creative Cloud workflows
  • Software: Adobe Creative Cloud (Photoshop, Illustrator, InDesign), VS Code, Canvas LMS
  • Supplies: External solid-state drive (SSD) for local backups, sketchbook for wireframing and structural planning

Learning Activities & Assessments

  • Asset System Project (Lab Benchmark): Build a personal digital infrastructure, establishing system file-naming conventions and cloud/local backup structures. This ensures foundational OS and workflow literacy.
  • Cross-Media Translation Project (Lecture + Lab): Translate a single visual concept into an optimized print poster (CMYK/300 dpi) and screen graphic (RGB/72 dpi+). This assesses understanding of resolution, color space, and format conversion.
  • Publication System Design (Lecture + Lab): Structure multi-page complex text using master pages, paragraph styles, character styles, and baseline grids. This evaluates typographic systems thinking and layout software fluency.
  • Responsive Screen Build (Lab Focus): Translate publication assets into a semantic HTML/CSS web layout adhering to accessibility standards. This assesses understanding of structured information, CSS grids, and accessibility defaults.
