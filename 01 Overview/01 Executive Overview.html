Executive Overview: Design Technology Sequence

Overview & Purpose

The Design Technology I & II sequence establishes the sophomore-level technological foundation for graphic design. Replacing the legacy "isolated software/tutorial" model, this sequence positions technology as an active design medium — framing it as the study of how information is structured, translated, produced, and made responsive across media.

Students move from managing file infrastructure to building scalable systems, developing durable habits in production literacy, web accessibility, systems thinking, and emerging AI workflows.

Position Statement

Design Technology is the study of how information is structured, translated, produced, and made responsive across media.

Regardless of specialization, contemporary designers work within complex technological systems. To design effectively across publications, interfaces, environments, or emerging media, students must understand how information behaves across varied platforms, formats, and contexts.

Broad View of Technology

Technology spans material, production, information, communication, and computational systems — from paper, typography, and web standards to design systems, component libraries, and AI-assisted workflows.

Critical Understanding

Technologies are never neutral; each carries inherent assumptions, defaults, and constraints that shape design outcomes. The goal is not software mastery for its own sake, but using technology as a vehicle to understand design deeply.

Core Capabilities

Students learn to:

  • Understand media and production constraints.
  • Translate information seamlessly across formats.
  • Build structured, scalable systems and responsive experiences.
  • Critically engage emerging tools and adapt to future workflows.

Format & Delivery Model

To balance conceptual rigor with hands-on execution, both courses utilize a high-impact Lecture / Lab Orchestration Model:

  • Lecture / Orchestrator (1 hr 10 min): Cohort-wide instructional session focused on core concepts, systems thinking, design history/ethics, technical logic, and live methodology demonstrations.
  • Studio / Breakout Orientator (50 min): Immediate hands-on breakout lab focused on tactical application, troubleshooting, peer critique, and guided project execution.

This structure ensures students move immediately from conceptual understanding to applied execution, eliminating passive tutorial consumption.

Design Technology I

  • Focus: Media, Translation, & Output
  • Core Shift: Moving from static software usage to understanding technological environments, print/digital constraints, and structured markup.
Unit Topics & Conceptual Rigor Assessment / Deliverable
Unit 1: Digital Foundations File structures, metadata, cloud/local OS mechanics, font licensing ethics, versioning. Asset System Setup: Standardized, scalable cloud/Local folder architecture following strict naming protocols.
Unit 2: Media & Translation Resolution calculations (300 dpi vs. 72 dpi), color spaces (CMYK/Pantone vs. RGB/Hex), substrates, ink limits. Cross-Media Package: Translated visual system as print-ready packaged vector/raster files and web graphics.
Unit 3: Publication & Info Systems Typographic grids, modular scales, baseline grids, master pages, paragraph/character styles. Multi-Page Publication System: Multi-page layout in InDesign enforcing structural grid hierarchy and automated style sheets.
Unit 4: Structured Screen Media Semantic HTML5, CSS Grid/Flexbox, WCAG accessibility standards (contrast, alt tags), fluid typography. Responsive Front-End Build: Functional, multi-page HTML/CSS site translating the Unit 3 publication layout to screen.

Design Technology II

  • Focus: Systems, Interaction, & Behavior
  • Core Shift: Moving from fixed media to dynamic, scalable, responsive, and generative systems.
Unit Topics & Conceptual Rigor Assessment / Deliverable
Unit 1: Interaction Foundations Information architecture (IA), user journey mapping, task flows, UX usability heuristics, wireframing. IA & Process Book: Complete low-to-mid fidelity wireframes, user journeys, and usability test results for a complex task.
Unit 2: Components & Design Systems Atomic design, Figma variables, design tokens, auto-layout, system governance, handoff documentation. Scalable UI Kit & Token Library: Documented, nested component system with global variables for light/dark modes.
Unit 3: Motion & Behavior Micro-interactions, temporal transitions, state changes, affordances, feedback loops. Interactive Motion Prototype: High-fidelity prototype showcasing complex component state transitions and motion choreography.
Unit 4: Responsive & Generative Systems Dynamic layouts, API integration, multi-breakpoint design, AI workflow bias/ethics, graceful degradation. Responsive/Generative Environment: Multi-breakpoint prototype using dynamic content/APIs, paired with an ethical audit essay.

Longitudinal Integration

Junior/Senior Level Reiteration

To maintain technical currency across the upper-division studio curriculum without adding credit bloat, concepts from ArtGr 2750/2760 can be reinforced through two proposed strategies:

Option A: The 1-Credit "Technology Module" (Recurring Lab)

  • Format: A 1-credit, repeatable workshop lab attached to Junior/Senior Capstone or Topic Studios.
  • Function: Brief, targeted deep-dives into rapidly evolving tools (e.g., advanced variable fonts, WebGL/3D UI, local AI integration, modern dev handoff) taken alongside 3000/4000-level project work.

Option B: Embedded Upper-Level Touchpoints

  • Junior Year (Systems & Interaction): Reiterate DTII 2760 Unit 2 & 4 principles by requiring live, tokenized design systems and responsive component libraries within Branding and UI/UX studios.
  • Senior Year (Capstone & Professional Practice): Reiterate DTI 2750 Unit 1 & DTII 2760 Unit 3 through mandatory pre-flight production audits, digital asset archiving, portfolio performance optimization, and interactive prototype presentations.
